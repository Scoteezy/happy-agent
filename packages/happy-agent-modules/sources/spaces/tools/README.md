# Spaces tools

`prioritizingTools` is Prioritizing's complete tool array: `list_sidebar`, `place_space`,
`set_space_visibility`, `set_space_icon`, `update_section`, and `remove_section`. Everything
except the icon is queued for the next calm moment. Each returns what happened in words.

`request_space_placement` is offered to every root conversation. It only briefs Prioritizing;
when the person asked explicitly, Prioritizing's result applies as soon as it finishes.
