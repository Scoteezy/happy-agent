# Spaces tools

`prioritizingTools` is Prioritizing's complete tool array: `list_sidebar`, `edit_sidebar`,
`get_sidebar_styles`, `set_space_icon`, and the ordinary artifact read/update tools. Layout edits
are exact-text replacements and wait for the next calm moment; icons apply immediately.

`request_space_placement` is offered to every root conversation. It only briefs Prioritizing;
when the person asked explicitly, Prioritizing's result applies as soon as it finishes.
